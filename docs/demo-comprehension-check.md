# Demo comprehension check

This is a **human-observation gate**. Automated tests, fixtures, screenshots, or an
agent must not be recorded as viewers.

## Setup

1. Start a fresh seeded build with the frozen Lagos bundle.
2. Open the explorer at Step 1.
3. Click **Use default timing & budget** to reach **Step 3 · Recommended package**.
4. Do not open the causal drawer, change a lens, fine-tune the plan, or explain the UI to the viewer.
5. Reset to the same default Step 3 state before each viewer.

The seeded default is used so every viewer sees the same deterministic package and
evidence state.

## Protocol

Recruit three people unfamiliar with the project. Show each person only the Step 3
recommended-package state for 30 seconds, then hide the UI and ask them—without
leading prompts—to identify:

1. the recommended three-zone package;
2. the currently permitted delivery claim and its Evidence D state; and
3. the primary reason the UI gives for recommending that package.

For each item, record the viewer's answer in brief anonymous notes before deciding
pass/fail. A viewer passes only if all three are materially correct. All three
viewers must pass the same UI state; otherwise revise labels/hierarchy and rerun the
full three-viewer gate.

Do not count familiarity gained from a previous failed run: if a participant has
already seen or discussed the product, replace them with a fresh viewer on the rerun.
